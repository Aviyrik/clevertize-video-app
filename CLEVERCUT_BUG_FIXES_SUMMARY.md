# CleverCut Bug Fixes & Improvements Summary

| Category | Bug Title | Bug Description | Steps to Reproduce | Expected Result | Actual Result |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Simple Studio / Runtime Stability** | Uncaught `ReferenceError: category is not defined` on Ad Script Generation | In Simple Studio (`SimpleBusinessStudio.jsx`), clicking the primary action button to generate ad script packages caused an unhandled JavaScript reference error (`category is not defined`), triggering the red "Creative Workspace Error" crash boundary. | 1. Open Simple Studio mode.<br>2. Enter any campaign brief (e.g. for Voxy) and click "Create 3 Video Ads". | Simple Studio should safely resolve the business category from available profile props or fall back to `'Local Business'`, then generate 3 ad script concepts without throwing an error. | Application crashed into the Creative Workspace Error screen with the message `"category is not defined"`. |
| **Simple Studio / UI & UX Clarity** | Misleading Call-To-Action ("Create 2 Video Ads") Before Script Selection | The initial step of Simple Studio displayed the button copy "Create 2 Video Ads" (or "Create 3 Video Ads"), confusing users into thinking raw videos were being produced immediately rather than generating creative script options first for user selection. | 1. Navigate to Simple Studio Step 1.<br>2. Observe the primary CTA button at the bottom of the brief form. | Button copy should clearly explain the script-first workflow (e.g., `"Generate 3 Ad Scripts ➔"`), and the subsequent screen should guide the user to select an ad script before generating a video (`"Produce Video for Selected Script ➔"`). | Button claimed it would create videos directly, bypassing the concept selection step in user perception. |
| **Simple Studio / Studio Controls** | Missing Video Dimension and Run-time Length Controls in Simple Studio | Simple Studio lacked controls for selecting video aspect ratio / dimension (`9:16 Vertical`, `16:9 Landscape`, `1:1 Square`) and target video length (`15s Hook`, `30s Standard`, `60s Extended`), forcing all simple scripts into hardcoded vertical 9:16 defaults. | 1. Open Simple Studio Step 1.<br>2. Inspect the options below the brief input. | Visual dimension selector cards (Vertical, Landscape, Square) and duration selector cards (15s, 30s with Popular badge, 60s) should be available and passed into the generation request. | Only Ad Language and Video Format selectors were rendered; dimension and length could not be chosen. |
| **Global Navigation & Project Lifecycle** | "Restart Film" and "+ New Film Project" Inoperative in Simple Studio | Clicking "Restart Film" in the top bar or "+ New Film Project" in the left navigation sidebar had no effect when operating in Simple Studio. The confirmation dialog was rendered inside Director Mode's tree, and Simple Studio lacked a reset handler or dynamic key to clear active inputs. | 1. Open Simple Studio and enter text into the brief field.<br>2. Click "Restart Film" at the top right or "+ New Film Project" in the left sidebar. | If active work exists, a global confirmation modal should appear asking to discard changes; on confirmation (or if empty), the studio should reset all inputs, clear scripts, and start fresh with an affirmative toast notification. | Neither button responded; clicks were completely ignored. |
| **Director Mode / Creative Settings & Backend Pipeline** | Inconsistent Platform/Duration Controls and Missing Aspect Ratio Enforcement | Director Mode Stage 02 Settings used legacy "2. Platform" (social media platform names) and "3. Duration" (15s, 20s, 30s) instead of matching Simple Studio's "2. Video Dimension" and "3. Video Length". Furthermore, `aspectRatio` and `dimension` were not explicitly tracked in Director Mode, passed to `buildSessionPayload()`, or enforced in `synthesizeMasterScript` Claude instructions and Magnific prompt framing. | 1. Open Director Mode and navigate to Stage 02 Settings.<br>2. Observe sections 2 and 3.<br>3. Synthesize a master script and compile shot specifications. | Stage 02 displays "2. Video Dimension" (9:16 Vertical, 16:9 Landscape, 1:1 Square) and "3. Video Length" (15s Hook, 30s Standard [Popular], 60s Extended). The user's choices appear in the "Your Choices" bar and script metadata strip, and are passed to the backend where Claude script synthesis and Magnific shot compilation enforce the chosen framing (Widescreen 16:9 / Square 1:1 / Vertical 9:16) and pacing. | Legacy platform and duration controls were shown; 60s duration was unavailable; aspect ratio was not propagated or enforced into script synthesis and shot prompts. |
| **Build & Environment Configuration** | Rolldown Native Binding Failure on macOS Apple Silicon | Running `npm run build` failed with `@rolldown/binding-darwin-arm64` missing because dependencies had been installed on an incompatible platform. | 1. Open the project on macOS Apple Silicon (ARM64).<br>2. Run `npm run build`. | Project builds production bundles cleanly via Vite and Rolldown. | Build failed with a missing native binding error. Fixed by adding `@rolldown/binding-darwin-arm64` to `optionalDependencies` and installing Darwin ARM64 binaries. |
